Documentação - Emissão de NFS-e Nacional (Protheus/TSS)

Objetivo​

Este documento tem como objetivo auxiliar na implantação e suporte da emissão da NFS-e Nacional no Protheus, relacionando os principais erros encontrados durante a transmissão das notas fiscais de serviço e suas respectivas soluções.

Erros de Validação

1. Telefone com caracteres especiais​

Mensagem​

Element '{http://www.sped.fazenda.gov.br/nfse}fone': [facet 'pattern'] The value '55-41-36144040' is not accepted by the pattern '[0-9]{6,20}'.

Causa​

O telefone do prestador está sendo enviado com caracteres especiais (hífen, parênteses ou espaços).

O schema da NFS-e Nacional aceita apenas números.

Solução​

Verificar o cadastro da empresa (SM0).

Os seguintes campos não podem conter caracteres especiais:

  • Telefone
  • Inscrição Municipal

Exemplo

❌ Incorreto

55-41-36144040

✅ Correto

554136144040

2. Descrição do serviço vazia​

Mensagem​

Element '{http://www.sped.fazenda.gov.br/nfse}xDescServ': [facet 'minLength'] The value has a length of '0'; this underruns the allowed minimum length of '1'.

Causa​

O campo xDescServ (Descrição do Serviço) está sendo enviado vazio.

O schema da NFS-e Nacional exige que esse campo possua pelo menos um caractere.

Solução​

Verificar se o Código do Serviço está corretamente cadastrado na SX5.

Esse cadastro é responsável por gerar a descrição enviada no XML.

3. Série inválida​

Mensagem​

Element '{http://www.sped.fazenda.gov.br/nfse}serie': [facet 'pattern'] The value 'NFS' is not accepted by the pattern '[0-9]{1,5}'.

Causa​

A NFS-e Nacional aceita apenas séries numéricas.

Foi enviada:

NFS

O schema aceita apenas:

[0-9]{1,5}

Solução​

Alterar a série utilizada na emissão da NFS-e.

Parametro:

ES_SERIESV

Exemplos válidos:

1
10
999

4. cTribNac não informado​

Mensagem​

Element '{http://www.sped.fazenda.gov.br/nfse}xDescServ': This element is not expected. Expected is ( {http://www.sped.fazenda.gov.br/nfse}cTribNac ).

Causa​

O XML foi gerado sem o campo cTribNac.

Na estrutura da NFS-e Nacional, esse campo deve ser informado antes do xDescServ.

Solução​

Verificar os seguintes cadastros:

TabelaCampo
SB1B1_TRIBMUN
SBZBZ_CODISS

Caso um desses campos esteja vazio ou incorreto, o XML será montado em desacordo com o schema.

Cadastros importantes

CadastroCampoFinalidade
SM0TelefoneDeve conter apenas números
SM0Inscrição MunicipalSem caracteres especiais
SX5Código do ServiçoGera o xDescServ
SB1B1_TRIBMUNTributação Nacional do Serviço
SBZBZ_CODISSCódigo ISS utilizado na geração do XML
SX6ES_SERIESVSérie da NFS-e (somente números)

Boas práticas

  • Validar os cadastros antes de iniciar a emissão da NFS-e Nacional.
  • Conferir o XML gerado antes da transmissão.
  • Manter este documento atualizado conforme novos erros forem encontrados durante a implantação em outras filiais.
  • Registrar sempre a mensagem completa retornada pelo schema para facilitar futuras consultas.
